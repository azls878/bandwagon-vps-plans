## 年付 49.99 的 20G KVM，限制在哪里

价格便宜，代价也写得明明白白。这个套餐有几条限制，下单前最好心里有数。

**流量与机房的换算规则**是最大的一个坑。20G KVM 套餐在普通机房享受完整的 1TB/月流量，但如果你把它免费迁移到 CN2 系机房（比如洛杉矶 DC3），流量会自动按套餐原流量的三分之一计算，也就是约 330GB/月。这是搬瓦工官方的规则，不是 bug。反过来，CN2 GIA-E 电商套餐迁移到任何支持的机房，流量都不打折。所以"买 KVM 再迁去 CN2 机房"这个省钱玩法，只适合流量消耗不大的人。

**性能层面**，1GB 内存、2 核共享 Xeon、20GB SSD，跑一个轻量网站、代理服务或学习用的 Linux 环境是够的；想跑数据库集群或者编译大项目，这个配置会捉襟见肘。所有套餐都是全 root 权限、独享 IPv4 一个、附带一个 /64 的 IPv6 子网，虚拟化是 KVM，控制面板是自研的 KiwiVM。

**KiwiVM 面板功能倒是给得不小气**：免费自动备份、免费快照、一键重装系统、手动挂 ISO、机房迁移、rDNS 设置、API 接口都在。第三方测评反复提到，这套面板是搬瓦工体验里加分较多的部分，做高危操作前先拍个快照，出问题能一键还原。

**SLA 与退款**。常规套餐承诺 99.95% 在线率，官网同时标注了 30 天退款政策。第三方整理的退款条件包括：账户注册 30 天内申请、此前未退过款、VPS 的 IP 未被封禁等，满足条件一般可全额退款。新账号注册时注意，退款看的是账户注册时间而不是单次购买时间。

## 线路实测：便宜款晚高峰会慢，这是线路决定的

如果你买 49.99 这档套餐主要是为了国内访问速度，需要先弄清线路分级。

年付 $49.99 的 KVM 款走的是普通线路，只有手动迁到 DC3 机房才享受电信 CN2 GT（联通、移动为直连）。第三方针对 DC3 机房的测评数据显示：全国平均延迟约 181 毫秒，电信平均约 172 毫秒，白天三网速度都不错，丢包不严重；但晚高峰电信速度会不稳定，部分测速节点掉到 10Mbps 以下。这是 CN2 GT 线路在晚高峰拥塞时的典型表现，不是机器坏了。

CN2 GIA-E 则是另一个档次的线路：三网回程全程 CN2 GIA，带宽 2.5Gbps 起步。第四方测评普遍反馈其国内平均延迟比普通线路低一截，晚高峰表现明显更稳。多付的那部分钱，本质上买的就是这条线路和"流量不打折"的迁移自由。

1. 纯粹想低成本折腾、建个个人博客、跑爬虫或学习 Linux——20G KVM 年付 $49.99 就够了，机房随便挑，流量 1TB 也用不完。

## 常见问题

**49.99 是月付还是年付？** 常规 KVM 和 CN2 系列的 $49.99 是年付；CN2 GIA-E 的 $49.99 是季付。下单时页面会标注计费周期，注意别看错。

**买 20G KVM 之后还能升级吗？** 可以在 KiwiVM 面板内迁移机房，但套餐本身的配置升降级和跨系列迁移（比如 KVM 迁到 CN2 GIA-E）并不支持，套餐之间是相互独立的产品。选之前想清楚用途，比买错了再折腾要省事。

**一台 VPS 能建几个网站？** 没有硬性限制，取决于你自己装的环境和 1GB 内存能撑多大负载。轻量级 WordPress 站点一两个没问题，再多就需要缓存优化或者换更高配置。

**流量超了会怎样？** 按搬瓦工的规则，超额后服务会被暂停直到下一个计费周期，所以用量大的场景要么选高流量套餐，要么做好流量监控。
